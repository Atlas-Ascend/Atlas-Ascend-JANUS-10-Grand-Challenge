# ATLAS PROMPT FABRIC v1

Estate-native prompt instruction set for JANUS PRIME. APF compiles operator intent into canonical context, bounded prompt primitives, Packet OS work, verification gates, proof receipts, and Thoth telemetry.

## Laws
- Patch before replace.
- Observed state before desired state.
- No self-promotion to PASS.
- Deployment is not proof.
- Every integration edge needs a contract and receipt.
- Failed work resumes from the failed gate.

## Default flow
`INTENT -> CONTEXT -> COMPILE -> PACKETIZE -> JANUS ROUTE -> WORKFORCE -> METAFORGE -> SECA/DEVOS -> MEDUSA -> PROOFGRID -> THOTH -> NEXT LOOP`
