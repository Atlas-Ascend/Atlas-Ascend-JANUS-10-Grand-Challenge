# APF Estate Adapters

- **Packet OS:** receives compiled atomic work packets.
- **JANUS PRIME:** owns intent classification, authority, routing and prompt composition.
- **Workforce Spine:** allocates packets to bounded specialist roles.
- **MetaForge:** implementation/build factory; cannot self-promote.
- **SECA / DevOS:** independent finish and verification gates.
- **Medusa:** security and public/private boundary review.
- **ProofGrid:** evidence graph and receipts.
- **Thoth:** context ingestion, telemetry, prompt-performance memory and hourly value measurement.
- **CrownGrid:** capability and estate I/O resolution.
- **Hypernet:** hardware/software capability execution fabric.

Adapters are contracts, not claims of live runtime integration. Each edge reaches VERIFIED only after healthcheck, test and receipt.
