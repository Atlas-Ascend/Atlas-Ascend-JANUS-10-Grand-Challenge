## Campaign Laws

1. One competition → one product → one repository → one submission ledger.
2. No fake completion. Every promotion requires evidence.
3. Competition rules outrank internal architectural preference.
4. No agent can self-promote its own output to PASS.
5. Sponsor technology must be materially executed when the competition requires it.
6. Deterministic demo mode must be visibly labeled and cannot masquerade as external execution.
7. Existing/pre-event work must be disclosed where event rules require provenance separation.
8. Public source is a submission gate when required; private build state is acceptable until then.
9. A successful deployment is not a final submission.
10. Winning is the objective; ten durable, independently demonstrable software systems are the minimum campaign artifact.
