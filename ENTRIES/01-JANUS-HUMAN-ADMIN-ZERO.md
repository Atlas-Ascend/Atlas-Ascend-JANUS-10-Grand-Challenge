## Product Thesis

A governed AI administrative agent that takes a messy real-world obligation, decomposes it into an auditable case graph and executable packets, uses bounded tools to complete repetitive administrative work, and returns receipts instead of claiming success.

## Judge-Visible Transformation

`human burden → structured case → agent plan → bounded action → verification → proof receipt`

## Required Sponsor Core

Strands Agents SDK must be material to the execution path. It cannot be a wrapper around a pre-computed result.

## MVP Proof

A user supplies one administrative objective containing multiple steps. JANUS identifies missing information, builds the case, executes at least one legitimate tool-mediated action, handles a failure/approval boundary, and presents a complete action ledger with evidence.

## Win Characteristics

- materially reduces repetitive admin work;
- clear agent autonomy without uncontrolled authority;
- robust stop/approval boundaries;
- observable execution rather than chatbot theater;
- reproducible demo;
- proof of sponsor technology;
- polished outcome understandable in under three minutes.
