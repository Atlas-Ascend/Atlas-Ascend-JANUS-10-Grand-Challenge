## Product Thesis

A reproducible agentic engineering forge that turns a product/build objective into a constrained implementation plan, code-change packets, tests, execution evidence and a final build receipt.

## Judge-Visible Transformation

`build objective → repository understanding → bounded engineering plan → generated/modified implementation → tests → repair loop → proof-backed artifact`

## Sponsor-Tech Contract

Use Nebius Token Factory or Nebius AI Cloud materially and satisfy current NVIDIA model/technology requirements. Preferred competition lane: Coding and Agentic Engineering, with Best Apps and Agents as secondary if category rules permit.

## MVP Proof

Give HEPHAESTUS a small but nontrivial repository and a feature request. It must inspect the codebase, plan changes, perform bounded edits, run verification, detect at least one failing condition, repair it and produce a change/proof ledger that another engineer can audit.

## Authority Limits

No unrestricted shell autonomy, no secret exfiltration, no destructive repository mutation without explicit policy, no self-promotion based only on generated prose.

## Win Characteristics

- real software engineering, not code-chat;
- coherent product UX around agent work;
- strong model/tool orchestration;
- deterministic verification loop;
- excellent observability;
- credible developer productivity impact;
- reproducible sponsor-tech evidence.
